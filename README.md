# CSE343 Lab 5 — Movie Watch List



A React-based movie watch-list application built for CSE343 Web Development Lab 5.



## Features



- Add movies with title, year, and genre.
- 
- Remove individual movies.
- 
- Write or update review comments.
- 
- Assign and change 1–5 star ratings.
- 
- Display ratings using star emojis.
- 
- Save the watch list in browser localStorage.
- 


## Run locally



```bash

npm install

npm run dev

```



Create a production build with `npm run build`.



The complete source code, screenshots, and report are included in this repository.
